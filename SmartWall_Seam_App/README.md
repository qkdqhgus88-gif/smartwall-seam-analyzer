# Smart Wall Seam Visibility Analyzer

65형 등 16:9 OLED 4모듈의 이음새 폭·시야각·픽셀 환산 폭을 비교하는 Streamlit 웹앱입니다.

## 시작하기

1. Python 3.10 이상 설치
2. 이 폴더에서 터미널 열기
3. 라이브러리 설치: `pip install -r requirements.txt`
4. 웹앱 실행: `streamlit run app.py`
5. 브라우저가 자동으로 열리지 않으면 터미널에 표시되는 `http://localhost:8501`로 접속

## 주요 기능
- 개별 모듈 55/65/77형 선택, 모든 모듈 해상도 3840×2160 고정
- 공통 내부 베젤 폭 및 패널 간 기구적 간격 슬라이더
- 시청 거리 설정 및 시야각/픽셀 환산 계산
- 화면 패턴: 흰색 / 컬러(연속 이미지) / 동영상(연속 영상)
- 컬러 이미지: 풍경/거실/도시 야경/추상 4종(실제 고해상 사진), 원본 1장을 네 영역으로 분할
- 동영상: 산 풍경/밤하늘 2종 내장. 선택 시 음소거 자동 반복 재생(배속 조절)되며 2×2 이음새를 겹쳐 표시(소리 없음)
- 실제 상대 치수 보기 / 이음새 확대 보기 / 이음새 표시 ON/OFF
- PNG 화면 저장 및 CSV 비교 결과 다운로드

## 과학적·공학적 해석 주의
- 실제 치수 비율 영상에서 이음새가 거의 보이지 않는 것은 화면 표시 축척의 한계입니다.
- 시야각 및 픽셀 환산은 기하학적 지표이며 사람이 이음새를 인지하는지를 확정하지 않습니다.
- 패널 내부 베젤, 기구 간격 및 임시 규격은 사용자 설계 가정입니다. 실측값이 아닙니다.
